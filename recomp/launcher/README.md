# Launcher artwork

`boxart.tga` is a placeholder card that names the game; it is not the
retail cover. It is used only to identify the game in the pre-boot
launcher. Replace it with the North American retail cover from
[libretro-thumbnails](https://github.com/libretro-thumbnails/Nintendo_-_Super_Nintendo_Entertainment_System)
when the project's artwork policy is settled, keeping the same file name.
